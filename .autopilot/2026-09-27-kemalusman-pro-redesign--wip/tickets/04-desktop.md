## Что должно заработать

Сайт на широком экране — тот же мир галереи: шапка со словесным знаком и навигацией, поиск,
баннер, фильтры (включая «Выбор Кемаля») и сетка 4–5 колонок сразу под героем, без пустой
чёрной полосы объявлений. Карточка по анатомии мобильной (одна метка, «от N сом» через
`formatSum`, цена за мл, без select «1500 с»), hover и фокус с клавиатуры. Товар открывается
существующим десктопным механизмом, оформленным заново. Корзина и оформление — не растянутая
мобильная колонка, а контент ограниченной ширины со сводкой рядом.

## Критерии приёмки

- [ ] Только токены (≈177 хардкод-hex заменены); шрифты — Playfair только для словесного знака, остальное системный стек; нет Georgia и Instagram-градиентов вне превью Instagram
- [ ] Нет пустой полосы объявлений (баг пустой строки, стр. ~199); на 1440×900 товары видны на первом экране
- [ ] Карточка: ≤ 1 текстовой метки, «Выбор Кемаля» вместо «By KemalUsman» без короны, `formatSum`, цена за мл, нет select «с»; hover + `:focus-visible`; кликабельные элементы — `button`/ссылки или `role`+`tabIndex`+Enter
- [ ] Корзина/оформление на десктопе ограничены по ширине, сводка заказа рядом; значения по умолчанию совпадают с мобильными
- [ ] Публичные props `DesktopLayout` не изменены; `npm run build`, `npm run lint` без новых ошибок; просмотр на 1440 и 1100px
