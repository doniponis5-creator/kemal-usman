## Что должно заработать

Каталог на телефоне выглядит как макет B из `palette-preview.html`: словесный знак, поиск,
баннер, чипсы (включая «Выбор Кемаля»), сетка белых карточек-постаментов. На карточке —
флакон, одна текстовая метка максимум, бренд, название, «от N сом» и «5 мл · N сом/мл»,
круглая «+» в акценте, маленькая кнопка аудио-заметки без таймера. Страница товара —
флакон на белом, объёмы двумя группами «Распив»/«Флакон» с ценой за мл, ноты пирамидой,
описание не склеено с нотами, блок «Похожие», компактная нижняя панель, аудио-описание
отдельным блоком.

## Критерии приёмки

- [ ] Сетка каталога соответствует макету B; на карточке ≤ 1 текстовой метки (Скидка → Выбор Кемаля → Новинка), нет цветных плашек и эмодзи; «Популярно/Хит» — сортировка «Популярные»
- [ ] Нигде нет «By KemalUsman» и короны; чипс «Выбор Кемаля»/«Кемалдын тандоосу» фильтрует товары с `isAuthor` и показывает подзаголовок «Оригинальные ароматы, которые выбрал Кемаль» (+ KG)
- [ ] В сетке нет плеера с «0:00 / 0:00» и тёмных градиентов; аудио — маленькая кнопка на фото; полноценный плеер — на странице товара
- [ ] «от N сом» и «N сом/мл» считаются только по вариантам в наличии с ценой > 0; товар без цены — «Нет в наличии» без «+»; KG: «1 500 сомдон баштап»
- [ ] Страница товара: группы «Распив»/«Флакон» (флакон — подпись содержит «Упаковка»/«флакон»), цена за мл у каждого варианта, пирамида нот, описание отдельно от нот, «Похожие» из `relatedIds` (если заданы), одна главная кнопка «В корзину»
- [ ] Карточка — `button` с `aria-label`; все тап-зоны ≥ 44pt; `aria-label` RU/KG; цвета только из токенов в этом регионе
- [ ] Логика корзины/избранного/отзывов не изменена; `npm run build`, `npm run lint` без новых ошибок; каталог и товар проверены в симуляторе на РУС и КЫР
