# Интерфейсы

## Правила проекта (читать до первой строки кода)

- Стек не меняется: React 19 + Vite 8, inline-стили (JS-объекты), Capacitor 8 iOS (SPM, не CocoaPods). Нового CSS-фреймворка, UI-библиотек, шрифтов с CDN не добавлять.
- Команды: `npm run build` (Vite), `npm run lint` (ESLint). Тест-скрипты `test:money`, `test:security` и все `pb:*` ходят на боевой сервер — **НЕ запускать**.
- iOS-сборка для симулятора: `npm run build && npx cap copy ios`, затем в `ios/App/CapApp-SPM/Package.swift` первая строка должна быть `// swift-tools-version: 6.2` (если откатилась на 5.9 — вернуть), затем
  `xcodebuild -project ios/App/App.xcodeproj -scheme App -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' -derivedDataPath /tmp/parfum-dd build`.
- Не трогать: `pb_hooks/` (серверные хуки — только отчёт, решение пользователя), `.env*`, `deploy*`, `scripts/pb-*`, данные на сервере. Никаких запросов на запись к `https://api.kemalusman.kg`, никаких входов по паролю.
- Не хватает зависимости — вернуть `BLOCKED`, не устанавливать.
- Логика (корзина, заказы, бонусы, рефералы, оплата, API) не меняется, кроме явно перечисленных исправлений админки в тасках 03 и 05.
- Язык интерфейса — RU/KG. Любая новая строка — ключ в обоих `src/i18n/strings-ru.json` и `strings-kg.json`.
- Секреты: никогда не копировать значения паролей, токенов, ключей, SID, телефонов, e-mail в код, комментарии, коммиты, отчёты.

## Границы, решённые в спецификации

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| Токены | палитра, светлая/тёмная | CSS-переменные `--ku-*` (spec §4.1), `T`, `R`, `card()`, `inputStyle`, `btnGreen()`, `btnOutline()` из `src/theme.js` | конкретные hex-значения |
| Карточка товара | анатомия карточки в сетке | `ProductCard` (props без изменений) | метки, аудио-кнопка, расчёт «от N сом» и цены за мл |
| Экраны магазина (моб.) | раскладка экранов | существующие компоненты экранов в `App.jsx` (props без изменений) | внутренние стили |
| Desktop | раскладка ≥1024px | `DesktopLayout` (props без изменений) | внутренние стили |
| Админка | экраны админки | существующие `Admin*Screen` (props без изменений) | внутренние стили и исправления |
| Нативная оболочка | цвет панели вкладок и фона | `LiquidGlassTabView` | значения оттенка |

Шов проверки один: публичные props компонентов не меняются; проверка — `npm run build`, `npm run lint`, ручной проход в симуляторе.

### Токены — точные имена (создаёт таск 01, используют все)

`--ku-bg`, `--ku-surface`, `--ku-surface-2`, `--ku-plinth`, `--ku-text`, `--ku-text-2`, `--ku-text-3`, `--ku-border`, `--ku-accent`, `--ku-on-accent`, `--ku-success`, `--ku-warning`, `--ku-danger`, `--ku-gold` (+ существующие `--ku-fill`, `--ku-fill-2`, `--ku-glass`, `--ku-glass-thick`, `--ku-text-dim`, `--ku-text-mid`, переопределённые под палитру B).
В `T`: `T.bg, T.bgSecond, T.white(=surface), T.card, T.plinth, T.text, T.textSecond, T.textMuted, T.border, T.accent, T.onAccent, T.success, T.warning, T.danger, T.gold` — все через `var(--ku-*, fallback)`. Старые имена `T.successIOS`, `T.bonus`, `T.referral`, `T.gray` остаются как алиасы на новые токены, чтобы не ломать импорты.
